# Andjing Telegram Bot (И ЦЗИН. Книга Перемен)

Telegram-бот для гадания по книге «И ЦЗИН». Позволяет получать случайные гексаграммы и их толкования, отправлять изображения и считать количество гаданий каждого пользователя.

## Возможности

- Гадание по кнопке и по тексту (вопрос в чат);
- Отправка изображения гексаграммы и полного описания;
- Поддержка счетчика гаданий для каждого пользователя (для статистики);
- Простое подключение.


## Быстрый старт

### 1. Клонировать проект
```
git clone https://github.com/master-click/andjing_bot.git
cd andjing_bot
```

### 2. Создать виртуальное окружение и установить зависимости
```
python -m venv venv
source venv/bin/activate # Linux/Mac
venv/Scripts/activate # Windows

pip install -r requirements.txt
```

### 3. Подготовить файлы

- Создайте файл `.env` и скопируйте туда ваш Telegram Bot Token:
```
TELEGRAM_TOKEN=ВАШ_ТОКЕН_ОТ_BOTFATHER
```

- Проверьте наличие/содержимое `data/hexagrams.json` и всех картинок в `images/`

### 4. Запустить бота
```
python main.py
```

## Деплой на сервер

Для автозапуска используйте systemd (для Linux) или планировщик задач (Windows). Пример юнита systemd — см. инструкции в репозитории.

## Админ-функции

- Счетчик гаданий каждого юзера сохраняется в файл `data/users_data.json`;
- Для выгрузки статистики используйте этот файл.

## Использование и распространение

Вы можете использовать бота для личного использования. Разрешена доработка, распространение при указании авторства. Использование в коммерческих целях запрещено.
